# task-7-

In this project, I created a small sales tracking system using Python and SQLite, which is a lightweight built-in database. I performed the following steps:

Created a SQLite database (sales_data.db) with one table called sales, containing product names, quantities sold, and prices.

Inserted sample data into the table for different products like Apples, Bananas, and Oranges.

Used SQL queries inside Python to calculate:

Total quantity sold per product

Total revenue (quantity × price) per product

Displayed the results in a table format using pandas.

Visualized the revenue using a simple bar chart with matplotlib.
